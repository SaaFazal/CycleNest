# CycleNest API

Multi-tenant e-commerce API built for high availability and low latency, handling complex geospatial data and scalable product inventories. 

## Features
- **Azure Cosmos DB Integration:** Scalable NoSQL backend designed for high throughput.
- **Geospatial Queries:** Real-time distance calculations using spatial indexing, Haversine formula, and Azure Maps integration.
- **Secure Authentication:** JWT-based user authentication and role management.
- **High Performance:** Architected to maintain low latency, load tested to handle 5,000+ requests per second.

## Tech Stack
- **Backend:** Java
- **Database:** Azure Cosmos DB
- **Cloud/Infra:** Azure Maps, JWT
- **Testing:** Apache JMeter
